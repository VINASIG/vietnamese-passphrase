# Vietnamese Passphrase 0.2.5

Release channel - research preview

This patch clarifies examples and diagnostic authorship and records the actual build environments. It adds no vocabulary revision or human evidence.

- README translations and CLI help present Unicode and ASCII examples together. Profiles, ordering and the illustrative 80-bit target are explicitly not recommendations; the library example has the same scope.
- Current documentation uses implementation-independent diagnostics and explains that the diagnostic code was authored within the project. No independent third-party review is claimed.
- CI and release jobs use ubuntu-24.04 and windows-2025-vs2026 labels. These labels avoid automatic OS-family migration while still receiving provider image updates.
- The schema-2 build record names two environment evidence files. Each records actual ImageOS/ImageVersion, OS release/version, architecture, hosted-runner type, Python/Unicode/Node/npm/Git versions, run/ref/attempt, dependency-lock hashes and four artifact hashes. Publication validates both exact-tag records before attesting all six release assets.
- Environment manifests are separate from the four deterministic, byte-compared distribution files. They identify the tested environment; they do not preserve a VM image or establish long-term hermetic reproducibility.
- Adversarial fixtures cover missing or changed image metadata and pins, source/tag/artifact/lock substitution, different workflow attempts, malformed records, environment-secret exclusion and evidence overwrite rejection.

All historical and experimental vocabulary bytes remain unchanged. No default profile, memorability advantage, typing advantage, regional approval, linguistic validation, independent security audit or production assurance is established. Existing licenses, attribution and private vulnerability reporting remain applicable.

Read [publication semantics](https://github.com/VINASIG/vietnamese-passphrase/blob/v0.2.5/docs/publication-semantics.md), [the release verification procedure](https://github.com/VINASIG/vietnamese-passphrase/blob/v0.2.5/docs/release-security.md) and [the research boundary](https://github.com/VINASIG/vietnamese-passphrase/blob/v0.2.5/docs/research-roadmap.md). Delivered observations are recorded separately after publication.
