Vietnamese Passphrase remains an agent-assessed research preview. This release adds an independent vocabulary audit, 180-configuration engineering comparison, four ablations, externally sourced VTB lexical attestation, explicit content and variant decisions, and five separate experimental profiles. It preserves every v0.1.0 wordlist byte.

CLI generation now requires an explicit profile. `verify` reports byte/format integrity rather than an overall approval. Entropy metadata names its uniform-sampling assumptions. Human-facing tables round model values.

New checks include a full-matrix neighborhood oracle, Unicode and corrupted-evidence fixtures, exhaustive uint32 boundary properties and tuple-encoding properties. Release distribution files are compared across Linux and Windows before keyless GitHub provenance attestation and publication.

The integration package and complete portable source archive carry the evidence and licenses needed for reuse. Read docs/adversarial-review.md, docs/assurance.md, docs/downstream.md and docs/release-security.md in the source archive or repository. The original production-input snapshot stays available in v0.1.0.

There is no completed independent security audit, human linguistic approval, user memorability study or production assurance. An agent headword screen is not an exhaustive semantic review. Diagnostic neighbors are not observed human-error rates. No profile is a recommended universal Vietnamese standard.

The unpublished v0.2.0–v0.2.2 tags retain packaging failures. npm console JSON varied from the assumed shape; then gzip streams differed across runtimes despite identical TAR contents, including at compression level zero. v0.2.3 checks the npm artifact directly and distributes ZIP_STORED archives with explicit metadata using the standard library. All four final files must still match across environments. Downloads are larger. Extract the integration ZIP to run its package/ CLI or install the extracted directory locally. The project remains private on npm, with no registry publication.
