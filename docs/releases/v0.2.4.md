# Vietnamese Passphrase 0.2.4

Release channel - research preview

This release corrects publication and product semantics. Both default READMEs lead with the current agent-assessed experiments and their evidence. The immutable v0.1 lists are separated into historical and diagnostic roles. There is no stable or human-validated Vietnamese vocabulary recommendation.

Canonical CLI profile names communicate experimental agent assessment, historical baselines, comparison controls or diagnostics. Old data identifiers remain deprecated aliases to the same bytes. The CLI and Python example reject generation from the retired high-confusability short list and the matched native comparison control. info requires an explicit profile, and profiles discovers scope without creating a secret. The generic library remains a caller-controlled generator and does not enforce catalog usage policies.

SECURITY.md defines the private vulnerability reporting channel, supported revisions, best-effort response targets, safe report contents and coordinated disclosure. docs/research-roadmap.md distinguishes further automated research from claims requiring actual Vietnamese participants. No participant evidence has been manufactured.

Release publication no longer hardcodes v0.2.3 notes. A fail-closed validator checks exact tag, package and lockfile versions, release metadata, notes path and heading, preview channel, source, artifact filenames, digests and the notes hash. Negative fixtures include a future v0.2.5 tag, stale or missing notes, corrupt delivery metadata and blocked profile generation. The publisher checks again before provenance attestation and publication.

Every published v0.1.0 and v0.2.3 data/release asset remains unchanged. This release changes usage semantics and implementation, not those wordlist bytes. Build evidence and attestations identify delivery origin, not linguistic approval or human performance.
