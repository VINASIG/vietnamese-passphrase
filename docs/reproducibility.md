# Reproduce the dataset and implementation

The project offers two distinct reproduction levels. Portable input evidence makes ordinary rebuilding independent of changing websites. Original snapshot verification checks how that evidence was reduced.

## Offline data rebuild

Use Python 3.12.14. There are no pipeline runtime dependencies.

```sh
python scripts/build_data.py --out output/rebuilt
python tests/data_test.py
python scripts/research.py
```

The first command verifies the portable input manifest and writes lists, complete dice tables, provenance, decisions, metadata and checksums into a separate destination. The tests build in a fresh temporary directory and compare every generated byte digest with the recorded revision. Input files, rules, ordering and JSON formatting are deterministic. No timestamps, secrets or ambient locale affect list bytes.

The research command recomputes all 180 sensitivity combinations, the POS model and the deterministic sentence holdout. The default production data is unchanged. Selection and corpus matching are documented in [research.md](research.md).

## Original snapshots

Generated entropy estimates use a 50-digit decimal logarithm, rounded to twelve decimal places. This avoids platform-specific binary logarithm differences changing metadata hashes. Selection uses integer evidence thresholds. List ordering does not use locale collation. Original license and attribution bytes are protected from Git newline rewriting. The runtime generator calculates its entropy estimate from the actual validated list size.

The [source lock](../data/source-lock.json) contains hashes for all original research inputs. Production uses four sources. Mutable download URLs may later serve a newer snapshot. A checksum mismatch is a failure, not a reason to update the hash automatically.

```sh
python scripts/acquire_sources.py --dest output/upstream --scope production
python scripts/prepare_sources.py --upstream output/upstream --out output/portable
```

Compare the four resulting portable files and their manifest against `data/inputs/`. If a live source changed, use the preserved source-snapshot archive for this revision or explicitly review a new data version. The local delivery includes a source-snapshot archive with the four original inputs, their notices, source lock and applicable licenses. It is a reproduction artifact, not a runtime dependency.

To reproduce all baseline comparisons, including the partial EFF translation experiment, acquire benchmark inputs as well.

```sh
python scripts/acquire_sources.py --dest output/upstream --scope benchmark
python scripts/benchmark_sources.py --upstream output/upstream
```

Benchmarks inspect GPL version 2 data separately and do not incorporate it into the production dataset. Every original source byte is verified before processing. This full upstream tier is separate from the smaller offline CI tier.

## Software and Python quality gates

Use the exact Node and npm versions in `.node-version` and `package.json`.

```sh
npm ci --ignore-scripts
npm run verify
npm audit --audit-level=low
python -m venv output/venv
# Activate that environment using your platform's documented command.
python -m pip install --require-hashes -r requirements-dev.txt
python -m mypy scripts tests/data_test.py examples
python -m ruff check scripts tests/data_test.py examples
python -m ruff format --check scripts tests/data_test.py examples
python tests/data_test.py
```

Hash-pinned Python development dependencies are separate from the dependency-free data pipeline and example. Prettier formats TypeScript and prose. Ruff formats Python. They do not overlap. Strict mypy checks function contracts. Dynamic JSON record bodies are explicitly typed at serialization boundaries, and source hashes and structural tests supply the runtime checks.

TypeScript is checked with strict mode, unchecked-index protection and exact optional properties. Typed ESLint has no unexplained warnings. Node tests cover real profiles, malformed input, corruption, mutable hash inputs, separator ambiguity, explicit targets, length constraints, random-source failure and all dice groups. Python independently verifies framing, evidence, folding, dice balance and deterministic rebuilds.

`npm pack` produces a local integration archive after building. It includes unminified ES modules, declarations, original TypeScript, wordlists, dice tables, selected provenance, source/data notices and applicable license texts. It does not include upstream caches, development tools or generated secrets. Full evidence and the ledger remain available in the source repository. The package is private to prevent accidental npm publication before a reviewed package release.

The CI definition runs the same source and offline data gates on Linux with Python 3.12.14 and Windows with Python 3.14.8. Both versions are pinned and must reproduce the same published bytes. A workflow file in a local checkout is not evidence of a remote CI run. Exact run status is recorded at publication.
