# Assurance boundary

The owner requires SI-agent execution and assessment. Evidence must name its layer and scope. There is no combined approval badge.

| Layer                             | Status                                               | Meaning and limit                                                                                      |
| --------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Automated integrity               | Verified by tests and rebuild commands               | Pinned bytes, tokens, transforms and parsers; not vocabulary-quality approval                          |
| Generator invariants              | Verified in covered fixtures                         | Source boundary, uniform mapping, replacement and encoding under assumptions; not an independent audit |
| Agent vocabulary assessment       | Headword screening completed; sense coverage partial | Single agent decisions with rationale; not native-speaker or linguistic approval                       |
| Reviewer feedback                 | Received through owner                               | Opposing hypotheses; identity, independence and inspected revision not established                     |
| Independent security review       | Not performed                                        | No completed independent auditor scope or endorsement                                                  |
| Human linguistic validation       | Not performed; outside agent-only execution          | No regional panel or observed familiarity, pronunciation or spelling acceptance                        |
| Vietnamese recall and entry study | Not performed; outside agent-only execution          | No measured recall, mistakes, preference or superiority                                                |
| Production evidence               | Not established                                      | No longitudinal deployment or incident record establishing fitness                                     |

Corpus attestation, model annotations and computed neighbors retain their names. A modeled measure is not a human observation. Passing an invariant does not prove the right UX objective. A signed release cannot change linguistic or user-evidence statuses.

Machine entropy remains precise for calculations. Human descriptions round it and state assumptions. No universal bit target or best vocabulary is asserted. User modification changes the model; downstream integrations must enforce actual constraints independently.
