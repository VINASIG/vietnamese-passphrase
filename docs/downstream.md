# Downstream redistribution guide

Commercial reuse is permitted by the stated licenses, subject to their conditions. This guide keeps data and library obligations separate. It does not replace the applicable license text or resolve every jurisdiction or distribution arrangement.

| Use                                               | Practical delivery                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vendor a UTF-8 list                               | Preserve the data license, creator/source credits, changes, source links and warranty notice. Ship NOTICE.md, LICENSES.md, applicable license texts and the selected revision's attribution records.                                                                                                                                                                          |
| Change spelling, selection or ordering            | Identify changes and retain earlier credits. Share covered adaptations under CC-BY-SA-4.0 or a permitted compatible adapter license; do not relabel upstream-derived data MIT.                                                                                                                                                                                                |
| Convert a list to minified JSON or a binary table | Pure technical format conversion is not automatically an adaptation. Embedding does not remove notices or grant additional restrictions on the covered data. Provide accessible attribution in an About/Licenses view or accompanying documentation.                                                                                                                          |
| Use data inside a larger app                      | A separate application does not automatically acquire the data license. Covered adaptations and certain database combinations may have their own obligations; identify the actual boundaries.                                                                                                                                                                                 |
| Redistribute the unmodified LGPL library          | Carry LGPL and incorporated GPL texts and notices, plus corresponding source and the relevant distribution terms. Use the full source archive for build inputs.                                                                                                                                                                                                               |
| Bundle or minify LGPL JavaScript with an app      | Minification does not remove LGPL obligations. Preserve notices, provide the corresponding library source and modifications, and satisfy the combined-work conditions, including permitted modification/reverse-engineering for debugging and replacement or recombination where required. A single opaque bundle with only a license link is not a complete compliance plan. |
| Implement a separate generator using only data    | The independently authored software has its own license. Data redistribution obligations still apply. Generated private secrets are not redistributed software merely because they were generated.                                                                                                                                                                            |

The data guidance follows [CC-BY-SA 4.0 sections 2–4](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en): attribution may reasonably fit the medium, technical format changes are distinguished from adaptations, and database rights can affect combinations. The [CC FAQ](https://creativecommons.org/faq/) explains collections and adaptations. Preserve Tatoeba's original CC BY 2.0 France credits as well as the combined dataset's grant. Corpus contributors do not endorse the product.

The library guidance follows [LGPL v3 sections 3–5](https://www.gnu.org/licenses/lgpl-3.0.html) and the incorporated GPL. The exact full texts are shipped in [LICENSE](../LICENSE) and [licenses/](../licenses/). Shared-library and recombination options depend on the actual delivery. Downloading browser JavaScript conveys a copy; a hosted-only label does not eliminate that question.

A useful attribution entry identifies Vietnamese Passphrase by VINASIG, its exact data revision, repository URL, CC-BY-SA-4.0, source notices and local changes. Keep an accessible copy of the full notices and detailed credits rather than substituting that short entry for all supplied attribution. Do not require end users to visit an unavailable URL to exercise their licensed rights.

Adoption friction is a real tradeoff: this dataset is not a permissively licensed drop-in. A future independent permissive source route needs its own rights and provenance. No such grant is asserted for the existing upstream-derived corpus.
