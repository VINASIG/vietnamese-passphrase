# Linguistic and memorability evaluation protocol

This protocol is a proposal. No participants have been recruited and no study has been performed. A word's corpus frequency is not a recall measurement.

## Linguistic review

Review all selected words independently of the filtering implementation. Recruit fluent Vietnamese reviewers with different regional backgrounds and document their roles and consent. Record familiarity, spelling acceptance, standalone use, imagery/concreteness, ambiguous or sensitive meanings and expected pronunciation. Retain disagreements and dialect context. Do not publish reviewer contact details or infer endorsement of the project's security claims.

Publish an attributable decision per disputed word. A rejected word needs a reason, not only a score. Review false exclusions as well as inclusions, using a sample from each ledger reason. Source labels are incomplete and cross-edition agreement is overlapping evidence. Separate contributions from final approval.

## Human study

Preregister hypotheses, measures, random assignment, exclusions and analysis before gathering observations. Use a small pilot to estimate variance, task duration and attrition. Calculate the required sample size from the chosen minimum meaningful difference and power. Do not choose a participant count merely because a small convenience sample is available.

Compare `vi` and `vi-short` at the same stated target, reporting their actual discrete entropy values. At the illustrative 80-bit target, their delivered values are 81.0453 and 82.6921 bits, so that difference must be acknowledged. To isolate accent entry, compare the ASCII vocabulary with its corresponding 2,464 native representative spellings using the same indices and draw count. Do not compare unequal vocabularies and describe it as an accent-only experiment.

Use counterbalanced tasks or randomized parallel groups, with practice separate from recorded trials. Record immediate entry time, entry mistakes, recall after one day and one week, abandoned attempts, user ratings and regional familiarity. Track whether participants wrote down their phrase, because this changes the memory task. If repeated learning is tested, treat it as a separate condition rather than assuming vocabulary alone caused recall.

Use disposable study phrases and an offline test environment. Never ask for a participant's real password, accounts, wallet seed or personal security habits beyond consented study variables. Retain minimal coded observations, delete private linkage data on the declared schedule and publish only consented aggregated results or properly anonymized records.

Report uncertainty intervals, effect sizes and missing observations. Use an analysis plan appropriate to repeated measurements and multiple comparisons. Record negative and inconclusive results. Do not claim easier memorization from a smaller list, lower mean length or a favorable subjective sample alone.

## Independent security review

Request review of the CSPRNG boundary, modulo rejection proof, source validation, input limits, Unicode transforms, injective encoding, dice mapping and package delivery. Verify the actual release bytes against the inspected source revision. A language reviewer, dependency audit or deterministic unit test cannot substitute for this scope.
